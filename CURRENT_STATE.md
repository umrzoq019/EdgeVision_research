# Current Project State

This checkpoint preserves the completed EdgeVision v2 experiments before the next improvement phase.

## Completed

1. Three small CNNs trained on CIFAR-10 using the v2 training pipeline.
2. Repeated single-thread CPU latency benchmark.
3. SmallCNNv2 → NanoCNNv2 knowledge distillation.
4. Three-setting distillation ablation.
5. v2 analysis script for accuracy/latency and validation-accuracy figures.

## Not yet completed

- INT8/post-training quantization
- established lightweight architecture comparison
- multi-seed statistical validation
- final Pareto analysis

Those should remain future experiments rather than being mixed into the current evidence.

## Artifacts

The `.pt` model checkpoints are generated by the scripts and are intentionally kept separate from the source-code package unless explicitly added later. The CIFAR-10 dataset is also not committed.
