# EdgeVision v2 Methodology

## Objective

Measure the accuracy/efficiency trade-off among three deliberately small CNNs on CIFAR-10, then test whether knowledge distillation can improve the smallest model without increasing its parameter count.

## Dataset

CIFAR-10, 32x32 RGB images, 10 classes.

The v2 run uses a deterministic subset protocol:
- 10,000 training examples considered
- 1,000 validation examples selected from that training subset
- remaining 9,000 examples used for training
- first 1,000 examples of the CIFAR-10 test set used for final evaluation
- seed = 42

Training augmentation: RandomCrop(32, padding=4) and RandomHorizontalFlip.
Evaluation: tensor conversion and CIFAR-10 normalization only.

## Models

### SmallCNNv2
3 -> 32 -> 64 -> 96 convolutional channels, followed by adaptive average pooling and a 10-class linear classifier.

### TinyCNNv2
3 -> 16 -> 24 channels, followed by adaptive average pooling and a 10-class linear classifier.

### NanoCNNv2
3 -> 8 -> 12 channels, followed by adaptive average pooling and a 10-class linear classifier.

Each convolution is followed by batch normalization and ReLU; max pooling is applied after the first two convolutional blocks.

## Training

- Optimizer: AdamW
- Learning rate: 0.001
- Weight decay: 1e-4
- Batch size: 128
- Epochs: 30
- Scheduler: cosine annealing
- Seed: 42
- Best validation checkpoint restored before test evaluation

## Efficiency measurements

The training script reports serialized state-dict size and CPU inference latency. The repeated benchmark uses one PyTorch CPU thread, 50 warm-up inferences, 500 measured inferences per round, and 7 rounds; median, mean, minimum, maximum, and per-round values are recorded.

## Knowledge distillation

SmallCNNv2 is frozen as teacher and NanoCNNv2 is trained as student. The main distillation run uses temperature T=4 and alpha=0.5, combining hard-label cross entropy and temperature-scaled teacher soft targets.

The ablation evaluates:
- T=2, soft-target weight 0.25
- T=4, soft-target weight 0.25
- T=2, soft-target weight 0.50

All ablation configurations keep the NanoCNNv2 student architecture unchanged.

## Reproducibility note

The repository preserves the completed result summaries separately from the source code. Checkpoint files are not required to understand the reported results, but exact latency reproduction requires the corresponding `.pt` checkpoints generated by the training/distillation scripts.
